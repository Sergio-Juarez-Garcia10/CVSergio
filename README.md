## 📖 Descripción del Proyecto

**CVSergio** es un portafolio personal desarrollado con **React** y **Vite**, diseñado para mostrar de forma visual y navegable toda mi información profesional. El sitio está organizado en secciones con navegación fija, resaltando la experiencia laboral, formación académica, stack tecnológico y proyectos destacados.

El proyecto incluye un flujo de publicación automatizado que compila la aplicación, despliega en **GitHub Pages** y sincroniza los cambios en el repositorio.

---

## ✨ Características

- 🧭 **Navegación fija y responsiva** con detección de sección activa al hacer scroll
- 📄 **Secciones completas**: Acerca de mí, Experiencia, Educación, Habilidades, Proyectos y Contacto
- 🎨 **Diseño moderno** con tipografías personalizadas (Google Fonts) y Font Awesome
- 📱 **Diseño adaptativo** para escritorio, tablet y móvil
- ⚡ **Rendimiento optimizado** gracias a Vite
- 🚀 **Despliegue automatizado** a GitHub Pages con un solo comando
